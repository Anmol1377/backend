SHEET 03 · READING ORDER

How to use this site

STEP A

Watch first

Run every figure before reading the prose. Your eyes will form the question the text answers.

STEP B

Break things

Kill a server. Overflow the queue. Shrink the cache. Failure modes are where the learning is.

STEP C

Score it

Finish in the arcade. If you can beat Status Rush on a streak, you've internalized it.
